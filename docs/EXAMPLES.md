# Example prompts

Paste these into Claude Desktop or ChatGPT once the server is connected.

**Check the setup**
> Check Illustrator status with a probe and tell me what version is running.

**Full design from a brief**
> Create a modern luxury skincare poster with a minimalist layout, beige background, elegant typography and a product image. Headline "PURE BEAUTY", subheadline "Radiance, refined". Save it as skincare-poster.ai.

**Plan first, then build**
> Plan (don't build yet) an A3 Swiss-style poster for a typography conference called "GRID 26". Show me the hierarchy and palette, then execute it once I approve.

**Brand kit** (uses the `brand_identity_kit` prompt)
> Make a brand identity kit for "Ember Coffee Roasters" — small-batch, warm, artisanal. Logo, brand board, business card and an Instagram post, all from base color #C8643B.

**Critique and improve**
> Critique the open document against the goal "clear focal point, readable from 3 m". Then apply the automatic fixes for alignment and contrast and show me before/after scores.

**Targeted revisions**
> In plan <id>: make the headline bigger, change background to navy, and move the logo up.

**Low-level control**
> Create an A4 CMYK document. Draw a 40 mm circle centered on the page in #C6A98A on a new "Graphics" layer, add "PURE BEAUTY" in Georgia 48 pt centered 40 mm from the top, then export a 150 ppi PNG.

**Variations**
> Generate 3 variations of a playful flyer for a kids' art camp — one per style, palette and layout — and build them.

**Production export**
> Save the document as final.ai, then export PNG (300 ppi), SVG (precision 2, outlined text) and PDF/X-4.

## UI design (Figma-AI-style)

**First-draft app screen**
> Create a sign-in screen for a fitness app called "Pulse" in a playful style with base color #5B2EFF.

**Landing page and dashboard**
> Design a modern SaaS landing page for "Acme Analytics" with the headline "Insights in minutes", then a web dashboard for the same brand.

**Design system**
> Create a UI kit for "Nova" in the corporate style so I can see the colors, type scale and components together.

**Custom screen with auto layout**
> List the UI components, then use create_ui_design on an iphone-15 frame to build a checkout screen: status bar, app bar with back button, order summary card, card-number and expiry inputs side by side, and a full-width "Pay $42.00" button pinned to the bottom.

**Wireframe**
> Make a low-fidelity wireframe of a mobile app home screen for a recipe app.

**Clean up layers**
> Rename the generic layers in the open document to meaningful names. Show me the suggestions first.
