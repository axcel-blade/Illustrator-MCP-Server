# Support

## Self-help first

1. Run diagnostics: Windows `scripts\diagnostics.ps1` · macOS `./scripts/diagnostics.sh`
2. Run the bridge smoke test: Windows `scripts\test-bridge.ps1` · macOS `./scripts/test-bridge.sh`
3. Check [docs/TROUBLESHOOTING.md](docs/TROUBLESHOOTING.md) and [docs/LIMITATIONS.md](docs/LIMITATIONS.md)
4. Look at the newest file in `logs/` (set `LOG_LEVEL=debug` for more detail)

## Getting help

| Need | Where |
|---|---|
| Question or how-to | [Discussions → Q&A](https://github.com/axcel-blade/Illustrator-MCP-Server/discussions) |
| Idea or feature request | [Discussions → Ideas](https://github.com/axcel-blade/Illustrator-MCP-Server/discussions) or a feature-request issue |
| Bug | [New issue → Bug report](https://github.com/axcel-blade/Illustrator-MCP-Server/issues/new/choose) |
| Works/doesn't work on your Illustrator version | Illustrator compatibility issue template |
| Security problem | [SECURITY.md](SECURITY.md) — never a public issue |

When asking, include your OS (Windows/macOS), Node.js, pnpm and Illustrator versions, the client (Claude Desktop / ChatGPT),
and the diagnostics output. Remove tokens and secret paths before posting.

This is a community project; support is best-effort.
